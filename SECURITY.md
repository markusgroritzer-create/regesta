# Security policy

## Scope

This policy covers the Regesta MCP package on npm (`regesta-mcp`), the Regesta servers, the REST API, the hosted MCP endpoint and the code in this repository.

## Reporting a vulnerability

Please report vulnerabilities privately, not in public issues:

- by e-mail to **security@regesta.io**, or
- through GitHub's private vulnerability reporting for this repository ("Report a vulnerability" in the Security tab).

Please include: the affected component and version, a description of the vulnerability and its impact, steps to reproduce or a proof of concept, and how we can reach you. Reports in English or German are welcome.

## What we commit to

These time limits are our own commitments, not statutory deadlines:

- We acknowledge receipt within **3 working days**.
- We send an initial assessment within **7 days**.
- We aim to fix critical vulnerabilities within **30 days**.
- Coordinated disclosure: we publish an advisory after a fix is available, at the latest **90 days** after the report. We delay publication only for a stated reason.
- On request, we credit the reporter in the advisory.

Security fixes are released separately from feature updates (own patch versions), free of charge and with notes on how to update. Advisories are published as GitHub Security Advisories.

## Security support

Latest minor version.

## Actively exploited vulnerabilities and severe incidents

Actively exploited vulnerabilities and severe incidents affecting the security of the product are reported under Article 14 of the EU Cyber Resilience Act (Regulation (EU) 2024/2847) through the single reporting platform to the coordinating CSIRT and ENISA: early warning within 24 hours, notification within 72 hours, final report as required there.

## Personal data breaches

If a vulnerability leads to a breach of personal data (for example in the alert service), the controller notifies the competent supervisory authority within 72 hours of becoming aware of it, unless the breach is unlikely to result in a risk to the rights and freedoms of natural persons (Article 33 GDPR).
