# Specification of Module 1 (German)

These files are the specification from which Regesta Module 1 is built (Phase B, released on 19.10.2026). They are kept in the code repository as a record of the human design decisions behind the code (build rule B1-1). They are copied unchanged from the project folder; references to other files point to that folder.

| File | Content |
|---|---|
| `00-vision.md` | What Module 1 is, for whom, and what it is not |
| `02-modul-1.md` | Exact scope: procedures, outputs, API, MCP tools |
| `03-datenmodell.md` | Data model, identifiers, provenance, versioning |
| `04-datenquellen.md` | Sources with licence, rhythm and limits |
| `05-architektur.md` | Architecture, hosting, security process |
| `07-design.md` | Design system |

Not in this repository: the legal assessment, the name check, the measurement protocol for the probe (published on the cut-off date), the boundary between open and paid features, the module plan and the decision log. They are kept by the licensor.
